# CÉREBRO — Site Pessoal Alquiran

## O que é
Site pessoal do Alquiran. Dark mode, hero com foto da orla, seção sobre, projetos.

## Arquivo principal
`index.html` (dentro desta pasta `site-pessoal/`)

## Como publicar
Este é um repositório git separado (`alquiran-site`)!
1. Editar `index.html`
2. Dentro da pasta `site-pessoal/`: `git add` + `git commit` + `git push`
3. Cloudflare deploya automaticamente em ~1 min

## URL
https://alquiran.pages.dev

## Design
- Dark mode completo
- Hero com foto da orla ao pôr do sol (parallax)
- Seção sobre com info real
- Cards de projetos
- Fotos do ensaio na galeria
